# Infinita-UI-UX

UI/UX Design Walkthrough: https://drive.google.com/file/d/1wR4lb44DGLtoVcn9O0fE_qJ98AZvOCQx/view?usp=sharing
Prototype : https://www.figma.com/community/file/1460580403696047962

Overview

A multi-category platform showcasing fashion, beauty, and global cuisine.

Subsections:

Fashion Fiesta: Features trending fashion and beauty products.

Integrated with virtual try-on technology for enhanced user experience.

Bunny Brews: Highlights a variety of cuisines including Chinese, Italian, and Continental.

Interactive food menu with customization options for dietary preferences.

Key Features :

Unified Design System: Consistent typography, color palette, and iconography.

Customizable Dashboards: Personalized user interfaces based on preferences.

Responsive Design: Mobile-first approach to ensure seamless access.

Design Highlights : Created wireframes and prototypes to represent a cohesive user journey.

Prioritized accessibility with high-contrast designs and intuitive layouts.

Outcome :

Delivered an engaging platform that boosts user engagement and retention through tailored experiences.
